# Ship in a Bottle

This is the rescue copy of an onion. It does not use trinitytrading.xyz.

The onion is a Solana account. This page reads that account through a public Solana node and asks the owner's wallet to sign one unlock. Unlock returns every lamport in the onion to that wallet and closes it. The sun is not an account in the instruction, and a flat close pays the sun nothing.

Leave, on the main site, is smaller. It stops sailors and returns only unused cranker fuel. Unlock is the full exit.

## Open it

Download this repository. In the folder, double-click `start-bottle.bat` on Windows or run `./start-bottle.sh`. Then open `http://127.0.0.1:8789/` in Phantom or Solflare.

A wallet will not attach to a file opened straight from the disk. The local page is what the wallet can see.
